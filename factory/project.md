harness-golden-path is a throwaway proof repo for the Control Harness Golden Path (ADR-001):
a minimal deterministic task harness (FastAPI + Pydantic v2 + PostgreSQL) with a task state
machine, claim/lease/heartbeat, idempotency, approval gate and append-only event log.
Requests that fix, test or document this harness belong here; production features,
new infrastructure or integrations with real Jarvis systems do not.
